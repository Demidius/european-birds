Сезоны в Польше

Можно выбрать несколько сезонов: достаточно совпадения с одним. Выбор сезона включает «Только Польша»; без выбранных сезонов эта галочка показывает все отмеченные в Польше виды. Один вид может относиться к нескольким группам.

Нажми на название, чтобы раскрыть ветвь, на фотокарточку - чтобы увеличить снимок. Показаны только виды, зарегистрированные в Европе.

Пунктир соединяет семейства с родами и виды с родом. Длина линий не показывает время или генетическое расстояние.

Польские названия для всех 423 видов взяты из Avibase, а для видов национального списка — из Komisja Faunistyczna. Название на польском само по себе не означает, что вид встречается в Польше.
