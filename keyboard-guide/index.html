Как настроить свою подсветку

  1. Fn + 9 или Fn + 0 - выбери один из двух профилей.
  2. Fn + Home - включи режим записи. Индикатор начнёт мигать.
  3. Нажимай нужные клавиши для включения или выключения их подсветки.
  4. Fn + End - сохрани получившийся рисунок.

Профили настраивают только подсветку, а не назначение клавиш.

Важно про модель

Сочетания взяты из руководства TECKNET EMK01707 (104/105 клавиш). Внешне клавиатура на фото похожа, но для точного определения нужна маркировка на нижней стороне. На другой модели некоторые комбинации могут отличаться.
