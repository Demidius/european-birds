# Птицы Европы · Воробьинообразные

Текущая страница содержит раскрываемое дерево с названиями. Фото, аудио, карточки, тесты, уровни и вход на ней не подключены.

## Состав и регион

43 семейства, 157 родов, 423 вида Passeriformes, зарегистрированные в регионе Europe по списку Avibase / Birds Canada: https://avibase.bsc-eoc.org/checklist.jsp?region=eur&list=avilist&lang=RU. Список проверен 14 октября 2026 года.

Из 436 региональных записей исключены 13 позиций с пометкой «Неопределенное происхождение». Сохранены 193 записи редких/случайных залётов и 13 интродуцированных видов. Переключатель «Показывать редкие залёты» скрывает первые; тогда остаётся 230 видов. Это список зарегистрированных видов региона, а не только гнездящихся или эндемичных. Границы региона, включая островные территории, соответствуют Avibase.

Научные названия и систематическое положение всех включённых видов проверены по AviList v2025b (AviList Core Team, 2026), https://www.avilist.org/checklist/v2025b/, CC BY 4.0. Все 436 исходных научных названий совпали с AviList; в отображаемом дереве - 423 принятых региональных записи. Русские названия взяты из регионального списка Avibase.

Синицевые ограничены европейским составом: 10 видов в 5 родах. Мировые 62 вида Paridae больше не отображаются на активной странице.

## Схема родства

Крупные эволюционные группы Tyranni, Passeri, Corvides, Passerides, Sylviida, Muscicapida и Passerida показаны по Oliveros et al. (2019), *Earth history and the passerine superradiation*, DOI: https://doi.org/10.1073/pnas.1813206116.

Взаимное родство всех семейств внутри крупных групп, всех родов и всех видов не реконструировано. Эти части дерева показывают систематическую принадлежность. Пунктир соединяет семейства с родами и виды с родом. Длина линий не отражает время или генетическое расстояние; виды перечислены без выдуманных пар ближайших родственников.

## Управление

- Название любой ветви раскрывает её дочерние ветви. Семейство -> роды -> виды.
- «Семейства», «Роды», «Виды» раскрывают дерево до выбранной глубины.
- «Свернуть всё» закрывает ветви.
- Поиск по русскому, научному или английскому названию показывает и раскрывает путь к совпадению.
- «Показывать редкие залёты» управляет региональным составом отображения.

## Запуск и файлы

`python3 -m http.server 8000` из корня репозитория, затем http://localhost:8000/.

Публикация GitHub Pages: main -> /(root). Сайт: https://demidius.github.io/european-birds/.

- `index.html`, `bird-tree.js`, `bird-tree.css` - текущая страница и раскрытие ветвей.
- `data-passerines.js` - региональные названия, состав и крупные группы, включая источники.
- `tools/build-passerine-tree.py` - воспроизводимая сборка из сохранённых JSON-выборок Avibase и AviList; путь к входным файлам и выходному JS задаётся аргументами.
- `sources/` - снимки исходных региональных записей и соответствующих строк AviList для повторной сборки.
- `assets/fonts/` - локальные шрифты с лицензиями OFL.

Прежние файлы занятий и медиа сохранены, но текущая страница их не загружает. Прежний прогресс не читается и не изменяется. При изменении CSS/JS увеличивать версии в index.html.

## Проверка

`npm test` проверяет полноту текущего регионального набора, уникальность видов, принадлежность к родам, исключение записей неизвестного происхождения и европейский состав синиц. `npm run test:browser` проверяет ширины 320, 390, 760, 1024 и 1440 px, все названия в раскрытом дереве, сворачивание семейств/родов, поиск, фильтр залётов, отсутствие учебного интерфейса и сохранность прежнего локального прогресса. Для браузерного теста нужен Chromium; путь задаётся BIRD_CHROMIUM.

Повторная сборка: `python3 tools/build-passerine-tree.py sources/europe-passeriformes-avibase-20261014.json sources/passeriformes-avilist-v2025b.json data-passerines.js`.
