# Птицы Европы · Дерево Синицевых

Текущая версия сайта показывает только дерево с названиями. Карточки, фото, аудио, тесты, уровни и вход на этой странице не подключены.

## Состав

Всё семейство Paridae: 13 родов и 62 вида по AviList v2025b (AviList Core Team, 2026), https://www.avilist.org/checklist/v2025b/, CC BY 4.0. Научные и английские названия импортированы из опубликованного короткого списка. Русские названия сверены со списком https://ru.wikipedia.org/wiki/Синицевые; для отсутствующих русских названий оставлены английские.

Ветвление родов - учебная схема по Johansson et al. (2013), https://doi.org/10.1016/j.ympev.2013.06.019, в актуальном составе родов AviList. Схема сопоставлена с опубликованной кладограммой https://en.wikipedia.org/wiki/Tit_(bird)#Systematics. Род Pardaliparus в AviList объединён с Periparus.

Сплошные линии показывают схематические отношения родов. Пунктиром обозначен список видов рода: взаимное филогенетическое родство видов не реконструировано. Длина ветвей не показывает время или генетическое расстояние. Aegithalidae и Remizidae не входят в это семейство.

## Управление

«Роды» сворачивает все списки видов, «Роды и виды» раскрывает их. Название отдельного рода сворачивает его ветвь. Названия доступны на телефоне и ПК без карточек или загрузки медиа.

## Запуск

Из корня репозитория: `python3 -m http.server 8000`, затем http://localhost:8000/.

Публикация: Settings -> Pages -> main -> /(root). Сайт: https://demidius.github.io/european-birds/.

## Файлы

- `index.html` - страница дерева.
- `data-paridae.js` - названия, состав семейства, топология родов и источники.
- `bird-tree.js` - отрисовка и раскрытие ветвей.
- `bird-tree.css`, `assets/fonts/` - стили и локальные шрифты.
- Прежние файлы занятий и медиа сохранены в репозитории для следующего этапа, но текущая страница их не загружает. Сохранённый прогресс не читается и не изменяется.

При изменении CSS/JS увеличивать версии в index.html.

## Проверка

`npm test` проверяет полный состав, уникальность видов, охват топологией всех родов и границы реконструкции. `npm run test:browser` проверяет ширины 320, 390, 760, 1024 и 1440 px, раскрытие ветвей, отсутствие учебного интерфейса и сохранность прежнего локального прогресса. Для браузерного теста нужен Chromium; путь задаётся BIRD_CHROMIUM.
