# Птицы Европы · Bird Atlas

Отдельный статический сайт на HTML/CSS/JS: без сборки и фреймворков. Идея и механика продолжает English File Skill Tree, но файлы, ключи браузерного хранилища и прогресс независимы.

## Дерево синиц

Доска открывается на вкладке «Дерево птиц». Первая ветвь содержит пять видов Paridae: московку, черноголовую и буроголовую гаичек, обыкновенную лазоревку и большую синицу. «Каталог» открывает все 38 видов.

У каждого вида есть фото, шкала знания 0–10 и кнопки «Карточка» / «Тест». «Проверить синиц» запускает смешанный тест по всем доступным синицам в выбранном режиме. Один верный выбор даёт +1, неверный −2; границы 0 и 10 сохраняются. Пропуск при недоступном медиа не меняет уровень. Фото, голос и названия используют существующий раздельный прогресс; новых ключей хранения не добавлено. В аудиорежиме доступны три вида с записями, остальные видны на дереве, но кнопка теста отключена.

Родственные связи сокращены до этих пяти видов по Johansson et al. (2013), *A complete multilocus species phylogeny of the tits and chickadees (Aves: Paridae)*, Fig. 1, DOI: https://doi.org/10.1016/j.ympev.2013.06.019. Промежуточные и остальные конечные ветви опущены. Длина линий не отражает время или генетическое расстояние. Две показанные гаички не объявляются ближайшей парой среди всех Poecile. Длиннохвостая синица относится к Aegithalidae и не включена в Paridae.

## Что работает

- Каталог 38 европейских видов, поиск по русскому, английскому, латинскому и польскому названию.
- Фильтры групп и прогресса; 38 реальных фотографий и 6 лицензированных записей голосов.
- Карточки по фото, голосу и названиям. До ответа вид не раскрывается. В режиме названий выбирается латынь, английский или польский.
- Интервальное повторение и уровень 0–10. Повторения выученных видов продолжаются.
- Независимые карточки для фото, аудио и каждого языка названия.
- Проверка введённого ответа; варианты названий; самостоятельная оценка четырьмя кнопками.
- Гостевой режим, резервный локальный прогресс для вошедшего пользователя, экспорт/импорт JSON, перенос гостевого прогресса в свой аккаунт.
- Общий Firebase Auth с English File; просмотр чужого прогресса без права изменения.
- Мобильная и широкая компоновка, шрифт Handjet для интерфейса, Manrope для пояснений. Шрифты лежат в assets/fonts, интернет для их загрузки не требуется. Лицензии OFL включены рядом.

## Запуск

```bash
python3 -m http.server 8000 --directory european-birds
```

Открой http://localhost:8000/. Для проверки без сетевого входа: http://localhost:8000/?offline=1.

## Firebase: точное дополнение

Проект использует `english-skill-tree-01`, как текущий сайт английского. Прогресс находится в:

```
profiles/{uid}/birdProgress/{speciesId}__photo
profiles/{uid}/birdProgress/{speciesId}__audio
profiles/{uid}/birdProgress/{speciesId}__names-latin
profiles/{uid}/birdProgress/{speciesId}__names-en
profiles/{uid}/birdProgress/{speciesId}__names-pl
```

Старые `cards`, `progress`, `tests` сайта английского не изменяются.

В правилах проекта, проверенных 14 октября 2026, уже есть разрешение чтения для вошедших пользователей и записи владельцем на `/profiles/{uid}/{rest=**}`. Оно распространяется на birdProgress, поэтому для запуска менять правила не нужно.

Если этого разрешения в другом проекте нет: в Firebase Console -> Firestore Database -> Rules добавь содержимое `firebase-birds.rules` ВНУТРЬ существующего блока `match /databases/{database}/documents`. Не заменяй остальные правила этим фрагментом. Он разрешает чтение только вошедшим пользователям, а запись - только владельцу профиля и только для проверенной схемы данных.

Если прежние правила содержат широкий `allow write` для любых путей, более узкий блок не отменит это разрешение: требуется проверить действующие правила, прежде чем обещать серверную защиту чужого прогресса. Приложение дополнительно блокирует редактирование чужого профиля в интерфейсе.

Если правила ещё не добавлены, занятия и локальное сохранение работают, но облачная синхронизация сообщает, что доступ пока не включён. После добавления правил перезагрузи сайт: несинхронизированные изменения сохранятся и отправятся в свой профиль.

Authentication -> Settings -> Authorized domains: добавь `demidius.github.io`, если он ещё не разрешён. Ник преобразуется в адрес тем же способом, что в English File. На одном домене браузер может использовать общий сеанс входа; на другом домене потребуется войти отдельно.

## Интервалы

«Снова»: 10 минут, уровень −2. «Трудно»: у новой карточки 10 минут, у изучаемой интервал ×1,2. «Хорошо»: впервые 1 день, затем прежний интервал ×лёгкость (начально 2,5). «Легко»: впервые 4 дня, затем дополнительный множитель 1,3. Уровни ограничены 0–10; интервал максимум 365 дней. Это простой планировщик, похожий по принципу на Anki, не точная копия алгоритма Anki/FSRS.

## Материалы и расширение

`data-birds.js` содержит данные и атрибуцию каждой фотографии/записи. Все материалы реально записаны/сняты. Лицензии и источники также перечислены в `CREDITS.md`. Файлы с названиями видов не показываются в интерфейсе до ответа. Аудио перекодировано в MP3, моно, 96 кбит/с; первые 60 секунд, если запись длиннее.

Первая база - учебный старт, а не полный список птиц Европы. Для достоверного определения следует добавлять фотографии самок, самцов, молодых и разные ракурсы, а для голоса - отдельные песни и позывки. Латинские и другие названия со временем требуют сверки с выбранным таксономическим списком.

Чтобы добавить вид, создай запись с уникальным `id`, четырьмя названиями, `group`, кратким `tip`, массивами `photos` и `audio`. Не ставь фиктивные ссылки: если массива нет, вид не включается в соответствующие занятия. К каждой записи медиа сохраняй автора, лицензию и ссылку на исходную страницу. Для одной птицы допускается несколько фотографий и записей: карточка выбирает вариант случайно.

## Проверка

```bash
node --test tests/scheduler.test.cjs
```

Перед правкой CSS/JS увеличивай версию в index.html. Изменения Firebase проверяются отдельно после применения правил и входа реальными пользователями.

## Структура

- `index.html`, `style.css`, `app.js` - интерфейс и занятия.
- `scheduler.js` - планировщик повторений.
- `bird-tree.js`, `bird-tree.css` - филогенетическая доска синиц и тест с автоматической оценкой.
- `data-birds.js`, `assets/` - виды и лицензированные медиа.
- `firebase-config.js`, `firebase-birds.rules` - общий Auth, отдельный прогресс и дополнение к правилам.
- `tools/` - сбор медиа и формирование базы; запускать только при осмысленном обновлении.
- `tests/` - проверки планировщика и приложения.

## Проверено в этой версии

- Браузер Chromium: ширины 320, 390, 760, 1024 и 1440 px, без горизонтального переполнения страницы и обрезания текста кнопок.
- Реальные занятия по фото, аудио и польским названиям; разные ключи прогресса; загрузка аудио; сохранение после перезагрузки; поиск по латинскому названию.
- Семь автоматических тестов планировщика.
- Тест с моделью Firebase: запись только в свой birdProgress, блокировка чужого профиля, игнорирование запоздавшего ответа при смене ученика, независимый гостевой прогресс.
- 38 изображений открыты для визуальной проверки; 6 MP3 проверены декодером и браузером.
- Реальная синхронизация Firebase не проверена: необходимо добавить правила и выполнить проверку с двумя аккаунтами.

Для дополнительных тестов установи зависимости: npm install. npm run test:accounts запускает тест прав доступа с моделью Firebase. npm run test:browser требует установленный Chromium; путь можно указать через BIRD_CHROMIUM.

Проверка доски: `npm run test:tree`. Проверяются ширины 320–1440 px, +1/−2, границы шкалы, защита от повторного ответа, общий прогресс с каталогом, сохранение после перезагрузки, разные режимы и безопасный пропуск при ошибке загрузки.
