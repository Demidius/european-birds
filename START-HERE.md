# Что осталось до публикации

Сайт готов в этой папке. Его можно запустить локально командой из README.md и уже заниматься без аккаунта.

1. Репозиторий создан: https://github.com/Demidius/european-birds. Файлы сайта загружены в корень ветки main.
2. Включить GitHub Pages: Settings -> Pages -> Deploy from a branch -> main -> /(root). Подключение GitHub в этой сессии не умеет создавать репозитории и менять настройки Pages.
3. Правила Firestore текущего проекта уже допускают чтение прогресса вошедшими пользователями и запись владельцем. birdProgress разрешён существующим `/profiles/{uid}/{rest=**}`; добавлять фрагмент для запуска не требуется. Домен demidius.github.io также разрешён в Authentication. Реальную синхронизацию нужно проверить после входа и ответа на карточку.
4. После публикации добавить ссылку на новый сайт в английский. Его текущие файлы я не изменял.

Предполагаемый адрес после публикации: https://demidius.github.io/european-birds/.

В архиве нет паролей и приватных токенов. Firebase-конфигурация - публичная конфигурация веб-клиента из текущего английского сайта. Защиту обеспечивает Firebase Auth и серверные правила Firestore.
