# Текущая версия

Сайт: https://demidius.github.io/european-birds/.

На странице - дерево зарегистрированных в Европе воробьинообразных: 43 семейства, 157 родов и 423 вида. Название любой ветви раскрывает её. Кнопки «Семейства», «Роды», «Виды» задают глубину всего дерева. Поиск раскрывает путь к нужному названию. У каждого вида есть фотокарточка; нажатие открывает увеличенный снимок с автором, источником и лицензией. Кнопки в окне переключают виды текущей выборки.

Редкие залёты можно скрыть переключателем. Неизвестное происхождение исключено; регион соответствует списку Europe в Avibase, включая островные территории.

Firebase и прежние занятия на этой странице пока не используются. Для дерева ничего настраивать в Firebase не требуется.

Источники, региональные критерии и границы филогенетической схемы находятся внизу страницы и в README.md.

Галочка «Только Польша» оставляет 184 вида из текущего дерева, подтверждённых польским национальным списком. На карточках есть тег «Встречается в Польше». Если убрать галочку редких залётов, останется 108 видов; редкость в этом режиме определяется для Польши.
