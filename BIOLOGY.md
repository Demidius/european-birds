# Биотопы и голоса птиц

`data-biology.js` дополняет текущую коллекцию из 435 видов. Ключ записи - принятое научное название в `BIRD_DATA`. Краткие русские описания биотопов относятся преимущественно к периоду гнездования; для редких залётных птиц описан обычный биотоп в основном ареале.

В `sources` сохранены видовые очерки, использованные для описаний. Текстовое описание голоса включено, когда сведения о голосе найдены в связанном очерке. Во всех карточках доступны ссылки поиска записей по точному научному названию. `reference` содержит конкретную запись xeno-canto, если она найдена.

`recordings` содержит до двух встроенных записей разных типов: `song` - пение, `call` - позывки и другие сигналы, `mechanical` - механические сигналы, `voice` - голос с неуточнённым типом записи. Тип следует метаданным исходной записи. Для iNaturalist выбраны наблюдения уровня Research Grade с совпадающим видовым определением. Автор, исходная страница и лицензия сохранены у каждой записи.

Встроены записи с CC0, CC BY или CC BY-SA. На другие записи xeno-canto даны только ссылки на исходные страницы. Доступность внешнего аудио зависит от его хостинга. Плееры загружают файл по запросу (`preload="none"`). При закрытии карточки воспроизведение прекращается.

`biology-sources.json` содержит сводку покрытия и источники по каждому виду. Дата проверки источников: 15 октября 2026 года. Учебные пересказы и производные справочные данные доступны под CC BY-SA 4.0 с указанием связанных очерков Wikipedia. Лицензии аудиозаписей действуют отдельно.

Проверки: `npm test` и `BIRD_CHROMIUM=/path/to/chromium npm run test:browser`. Они проверяют покрытие всех видов, метаданные источников и лицензий, отображение карточек и отсутствие горизонтального переполнения на телефонах.
